# 热血城邦

免费的古希腊风城邦战争。没有浏览器插件钱包，没有粮草石头数字。人物卡没有基础属性，只记下你打过的战役。

在游戏里点右上角语言，或打开「帮助」，即可切换界面与游玩指南。城邦名、公会名由你自己起，不会随语言改掉。

**现在就玩：** [热血城邦](https://maya970.github.io/rexue-chengbang/)

## 怎么开始

1. 打开游戏，点「游戏内创建钱包」。密钥只留在你的浏览器里，可随时导出、导入。不需要安装任何钱包插件。
2. 在大地图上点一块地，起名，加入建城指令。
3. 点底部「执行指令」。指令排队后才会真正发出。

玩本身不收费。人物卡货架成交时买家才付钱：九成给卖家，一成手续费。

## 建立城邦

- **第一座城**可以建在平原、森林、海岸、山地或海域。
- **海港城**建在海域，自带港口、船厂和运输船。
- **山城**易守难攻，没有港口，翻山行军更慢。
- **第二座城起**必须先侦察邻格、打通走廊。出征「开辟殖民市」需要 3 张人物卡，并消耗奴隶和物资。**海域不能殖民**，海岸和陆地可以。
- **不能攻击自己的城，也不能攻击同公会成员。** 公会成员共享已打下来的格子。

## 十座建筑，各管一件事

每种建筑都有专属作用，不是同一套数值换皮。

- **卫城**：其他建筑的等级不能超过它，并提供总招募名额。
- **市政广场**：每级缩短建造时间；每 4 级多允许一座建筑同时在建。
- **民居**：公民卡上限，也是公民名额的主要来源。
- **兵营**：重装步兵、轻盾兵、海军陆战的人数上限。
- **马厩**：骑兵人数上限。
- **弓营**：弓手人数上限。弓手站第二排按地形宽度放箭，但更脆弱。
- **城墙**：守城时增加地形宽度，让更多人同时出手。
- **神庙**：守军更难崩溃；本城打过的战役按神庙等级加倍记入成果。
- **造船厂**：招募舰长、三列桨座和运输船。只有海岸或海域城能建。
- **海港**：没有港口不能出海；等级加快海路行军。只有海岸或海域城能建。

## 出征

出征必须指定**出发城邦**，并勾选将士。点地块只是目标，不会自动派兵。

- 走海路需要港口和运输船。
- 海上交战还要三列桨座和舰长。
- 侦察与增援走海路，只需港口和运输船。

系统小镇出现在每 100、1000、10000 格：可以占领、劫掠、屠城，**不能毁灭**。

## 顶栏四块木板

点顶栏会打开带滚动条的大木板，可搜索、分类。

- **战报**：派出的军团到达后，写进你的个人回报，并保存在本机。按胜负、任务检索。
- **货架**：人物卡上架免费。成交九成给卖家，一成手续费。必须先有自己的城才能买卡。
- **公会**：共享连通格子。退出后一个月内不能加入其他公会。
- **超大地图**：俯视总览。搜海图名、坐标（如 0,0）或你的城邦名，点一块进入立体大地图。

旁边还有 **帮助**：多语言游玩指南，和这四块木板一样是大页面。

## 我的名册

名册列出你的城邦、人物、奴隶、物资和在途军团。点一项才会跳转，不会把名字铺在地图上。

## 更多语言

游戏内「帮助」与顶栏语言选择提供约六十种官方语言的界面与指南，方便不同国家的玩家一起玩。城邦名和公会名始终保持你输入的原文。
