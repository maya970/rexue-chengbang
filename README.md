# 热血城邦

古希腊 SLG 战报链游。没有第三方钱包弹窗，没有粮草石头，没有兵力数字。

## 怎么玩（完全免费）

默认 **本地**：打开就能建城打仗，**不要钱包、不要插件、不要点签名**。身份只存在浏览器里。

想联网时切 **Permabin**。这时才在游戏内点「创建钱包 / 导入 / 导出」。密钥不离开浏览器，指令后台写入，**没有第三方钱包弹窗**。Permabin 对 ≤100KiB 的指令批次免费。

人物卡货架成交才花 AR（九成卖家、一成手续费地址）。玩本身不收费。

## 规则

- **时间** 由这座城自己的地形倍率、你有几座城、你有多少张人物卡和奴隶卡共同决定。
- **奴隶卡** 不能招募。只能战斗抓获，或用本城物资卡购买；可编入军团，也可转成公民。敌军打进城里时，人物卡和奴隶卡一样按地形宽度挨打。
- **物资卡** 来自劫掠和屠城。可买奴隶，也可和奴隶一起折成建造材料。
- **建造不能无限排队。** 每城同时只许一项工程；开工会占用监工人物卡并消耗物资/奴隶，占用期间不能拿去干别的。
- **进攻** 必须把路径上连通的敌对聚落全部清空。部落刷新在固定地块，不会搬家。
- **视野：** 加载一座城只看见这座城里的奴隶和名册。不属于你的地块不加载细目。
- **人物卡货架：** 上架免费。成交时买家付 AR，九成给卖家，一成打入手续费地址 `B1E8CDbmVVLuYHXiheFXbW4E0F1gpGBhpIWTOi2AFi0`。付款交易进块后即过户，卖家随后撤架无效。
- **建筑物** 决定公民人数、招募人物卡上限、以及「成果」。每座楼、每座城都记下经历过的战争；**毁灭后从世界上彻底删掉**。
- **人物卡没有基础属性。** 只记参加过的战役。打得越多越强，但链上随机位数永远可能让最强的人死掉。
- **出海必须有港口**，再带运输船；攻城出海还要三列桨座和舰长。
- **打赢后三选一：** 劫掠（一部分奴隶卡和物资卡、少毁楼、城不换主）、屠城（更多奴隶和物资、大毁建筑、易主）、毁灭（城市与建筑消失）。士兵相对公民太少时，毁不了太多楼。
- **战斗：** 用交易号当位数随机数。先判先手，再按地形宽度（例如宽 10）每轮最多 10 人同时打对面的人，然后换手，直到一方士气崩溃或全灭。士气取在场平均值，战役越多越难崩溃。

- **野怪：** 地图上有大量分等级的原始部落与海盗；等级越高越难打。被毁灭后按等级间隔刷新。
- **3D：** 大地图与城内用 Three.js。双击或「进入城市」走进广场，看到圆柱、建筑和走动的人；操作一律弹窗，不在 3D 里填表。

指令队列：`排队中` → `排队中（已上传）` → 链上能查到才 `发送完毕`。这是联网战报，本地只是延迟窗口，不是单机权威。

## 数据为什么会变大，以及怎么办

链游必须能从历史重建世界，体积会随对局增长。这里用三层把可玩性保住：

1. **检查点 + 一次折叠：** 历史批次 `foldHistory` 只算一遍；当前时间按 2 分钟对齐后 `projectWorld` 投影一次。客户端核检查点 digest，两个 GraphQL 网关交叉核对交易号，漏单则丢弃检查点改拉全链。
2. **删除：** 阵亡的卡、被毁灭的城不再留在状态里（战报里还有名字）。
3. **指令本身很小：** 每批 JSON 压在免费 100KiB 内。

不信任检查点时，仍可用全部 Permabin 批次从头核验。

## 运行

```bash
npm install
npm run dev
```

打开即可玩。GitHub Pages 由 `main` 分支自动部署。Vercel 环境变量：`VITE_GITHUB_REPO=用户名/仓库名`。允许 Actions 写入 `world-index` 与 `gh-pages`。
